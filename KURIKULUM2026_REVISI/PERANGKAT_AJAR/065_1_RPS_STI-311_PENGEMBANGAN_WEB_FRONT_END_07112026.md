## Deskripsi singkat mata kuliah

Mata kuliah ini melatih penyusunan antarmuka web dasar hingga menengah menggunakan HTML semantik, CSS dan Flexbox, responsivitas, pengenalan Bootstrap dan Tailwind, serta JavaScript dasar dan DOM/event. Mahasiswa membangun kalkulator dan landing page, menguji navigasi, interaksi dan tampilan, serta mendokumentasikan hasil. Pembelajaran menggabungkan teori, praktik terbimbing, penugasan dan belajar mandiri. Kontribusi mata kuliah kepada CPL dibatasi pada keterampilan dasar front end.

## Bahan kajian: materi pembelajaran

HTML semantik, konten, tabel dan formulir; CSS, box model, media query dan Flexbox; Bootstrap dan Tailwind dasar; JavaScript, aritmetika, DOM/event; kalkulator; landing page responsif, pengujian dan dokumentasi.

## Lingkup dan fasilitas

Dalam lingkup: HTML/CSS dasar–menengah, Flexbox lanjutan, Bootstrap dan Tailwind dasar, JavaScript dasar dan DOM/event, kalkulator dan landing page. Di luar lingkup: React/Vue/SPA, Fetch/asinkron/API, backend, database dan build pipeline. Validasi klien bukan keamanan server; data harus dummy atau berizin. Siapkan editor, browser, CSS Bootstrap dan stylesheet Tailwind dengan semua kelas yang dipakai agar latihan dapat berjalan tanpa internet, Node.js atau konfigurasi build.

Skor tiap instrumen adalah jumlah skor kriteria (0–100) dikalikan bobot kriteria. Nilai akhir MK = (20 × Tugas 1 + 25 × UTS + 25 × Tugas 2 + 30 × UAS) / 100. Satu CPMK utama dipetakan pada setiap instrumen agar tidak dihitung ganda. Ketercapaian CPL lintas MK mengikuti Dok 008 dan kebijakan prodi; 45% dan 55% bukan otomatis skor CPL. Tugas 1, Tugas 2 dan UAS direncanakan sebagai kasus/proyek (75% bobot), bukan klaim realisasi IKU; bila berkelompok simpan bukti kontribusi dan lakukan penjelasan individual. Remedial dan ambang ketuntasan mengikuti kebijakan prodi.
