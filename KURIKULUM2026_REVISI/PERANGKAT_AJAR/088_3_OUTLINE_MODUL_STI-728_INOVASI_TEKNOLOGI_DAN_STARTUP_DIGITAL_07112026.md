## 3. Rincian Materi per Modul

### M1 — Ekosistem Startup (Mg1)
**Topik:** Unicorn Indo, founder archetypes, Lean Startup 5 prinsip, BML loop, pivot types (zoom-in, customer segment), innovation accounting  
**Ideasi:** Crazy-8 (8 ide/8 menit) → dot voting → 3 shortlisted, team formation 4-5 org  
**Sumber:** Ries Ch1-3, Startup Report

### M2 — Customer Discovery (Mg2)
**Topik:** JTBD, pain vs gain, interview script (intro, context, pain deep-dive, wrap), 5 whys, avoiding leading questions, recording consent  
**Fieldwork:** 15 interviews (kampus/UMKM), audio record, transkrip bullet points, affinity map (pain clusters)  
**Sumber:** Ries Ch.4, JTBD

### M3 — Lean Canvas (Mg3)
**Topik:** 9 blok: Problem (top 3), Customer Segments, UVP (formula: headline+sub+benefit), Solution (top 3 features), Channels, Revenue, Cost, Key Metrics (DAU, conversion), Unfair Advantage  
**Workshop:** Isi canvas per tim, gallery walk critique (is UVP unique?)  
**Sumber:** Ash Maurya

### M4 — Jenis MVP (Mg4 — TUGAS1)
**Topik:** Landing Page (smoke), Concierge (manual service via WA), Wizard of Oz (seolah-olah AI padahal manual), Prototype (Figma), mana untuk hypothesis mana  
**Contoh:** Dropbox video MVP, Zappos concierge, Buffer landing page  
**Output Tugas1:** Canvas final + interview report 5-8 hal (demografi 15, pain list, 5 quotes verbatim, insight 3) + MVP plan (hypothesis, MVP type, metric, next step)  
**Sumber:** MVP types

### M5 — Landing Page MVP (Mg5)
**Topik:** Builder (Carrd/Webflow/Wix), copy (headline pain-solution, CTA "Join Waitlist"), analytics (GA4 page_view, cta_click events, Hotjar heatmap), domain edu (mis. timname.netlify.app)  
**Hands-on:** Build + publish, install GA, test events  
**Sumber:** Landing guide

### M6 — Smoke Testing (Mg6)
**Topik:** Traffic (IG Ads dummy $0, campus poster QR 50 scans target), conversion (clicks/visits), A/B (headline A vs B), ethics (no fake payment)  
**Hands-on:** Launch 3 hari, collect 50+ visits, hitung conversion, iterate headline jika <5%  
**Sumber:** Smoke Test

### M7 — Sprint0 Perancangan (Mg7)
**Topik:** Wireframe 5 screens (onboarding→core→result→profile), arch (FE Next.js, BE FastAPI/mock, DB SQLite, AI API opsional), backlog MoSCoW, story points  
**Hands-on:** Figma wireframe + arch diagram draw.io + Trello backlog Sprint1/2  
**Sumber:** Figma, SDLC Agile

### M8 — UTS Pitching Validasi (Mg8)
**Agenda:** 8m presentasi (problem, 3 quotes insight, canvas, landing results: visits, conversion, insight, next) + 7m Q&A (kenapa problem ini penting? bukti?)  
**Kisi:** Mg1-7, evidence interview & landing data wajib  

### M9 — Sprint1 Core Feature (Mg9)
**Topik:** Core smart feature: contoh — AI: chatbot RAG (OpenAI API) / Platform: marketplace cart / IoT: dashboard sensor (dummy) — integration, daily standup, review  
**Hands-on:** Coding Sprint1, deploy Vercel, changelog (what built, what blocked)  

### M10 — Sprint2 Polish (Mg10)
**Topik:** UI polish (design system, colors, spacing), onboarding (tutorial 3 steps, tooltips), retention (reminder WA/email dummy), bug bash, UAT 5 users (SUS 5 pertanyaan)  
**Hands-on:** Polish + UAT, catat feedback  

### M11 — AARRR (Mg11)
**Topik:** Pirate Metrics: Acquisition (channel, CAC), Activation (onboarded 60%), Retention (D7 30% target), Referral (K-factor), Revenue (paying 5%) — dashboard Amplitude/Mixpanel simulasi, cohort (users minggu1 vs minggu2)  
**Hands-on:** Dashboard funnel dari data MVP/landing (dummy if needed)  

### M12 — Unit Economics (Mg12 — TUGAS2)
**Topik:** CAC = spend / paying, LTV = ARPU×GPM×(1/churn), churn = lost / total, payback = CAC / (ARPU×GPM), burn = monthly cost, runway = cash / burn, break-even users  
**Hands-on:** Hitung dari landing/MVP data, laporan 2-3 hal (CAC, LTV, LTV/CAC >3 healthy, runway 12m target)  
**Output Tugas2:** MVP v1.0 URL+repo+video 2m + AARRR dashboard + Unit Economics laporan  

### M13 — Pendanaan (Mg13)
**Topik:** Angel (cap $10-50K), Seed ($100-500K), Series A ($1M+), valuasi pre/post-money, cap table (founders 70%→diluted), ESOP, term sheet (liquidation 1× non-participating, vesting 4y1y cliff)  
**Panel:** VC/East Ventures / angel kampus (2h), Q&A cap table simulasi  

### M14 — Pitch Deck 10-Slide (Mg14)
**Topik:** 1 Cover (one-liner), 2 Problem (pain + $), 3 Solution (demo GIF), 4 Market (TAM/SAM/SOM bottom-up), 5 Product (screenshot), 6 Traction (landing+MVP metrics), 7 Business Model (pricing), 8 Go-to-Market (channel), 9 Team (founder-market fit), 10 Financials & Ask (raise $X for Y months runway) — storytelling hero's journey  
**Workshop:** Draft 10 slides, peer feedback (is ask clear?)  

### M15 — Rehearsal (Mg15)
**Topik:** Delivery: voice (pace 140wpm), body (eye contact), timing 5m (rehearse 10×), handling Q&A (Acknowledge-Bridge-Answer, jujur "I don't know but will check")  
**Hands-on:** Dry run 5m + mentor feedback 10m per tim (timing, clarity, defensibility)  

### M16 — Demo Day (Mg16 — UAS)
**Agenda:** 5m pitch (deck 10 slides), 5m live MVP demo (klik real, bukan video), 5m Q&A panel (market size valid? CAC payback? moat? competitor?)  
**Output:** Deck final + MVP URL + dashboard + laporan + video 3m  
**Kriteria lulus:** Demo live sukses, CAC/LTV terhitung, pitch persuasive
