## B. Rencana Mingguan

### Mg1 — Ekosistem Startup & Lean Startup (C2)
**Bahan:** Unicorn Indonesia (GoTo, Traveloka), founder traits, Build-Measure-Learn, pivot vs persevere, 5 prinsip Lean Startup  
**Metode:** Kuliah 100m + Lab Ideasi 170m (100 ide crazy-8 → 3 terbaik) + Mandiri 180m (baca Ries Ch1-3)  
**Tugas:** Ide board (100 sticky notes) — non-graded  
**Sumber:** Ries, Startup Report 2024

### Mg2 — Customer Discovery & Problem Interview (C4)
**Bahan:** JTBD, pain points, interview script (open-ended), 5 whys, bias interview, recording & transkrip  
**Metode:** Case 50m + Fieldwork 170m (wawancara 15 responden di kampus/UMKM, rekam audio) + Studio 50m debrief  
**Output:** Interview notes 15 + affinity map  
**Sumber:** Ries Ch.4, JTBD

### Mg3 — Lean Canvas & UVP (C4)
**Bahan:** Lean Canvas 9 blok (Problem, Solution, Key Metrics, UVP, Unfair Advantage, Channels, Customer Segments, Cost, Revenue), UVP vs positioning  
**Metode:** Workshop 270m — isi canvas per tim, peer critique gallery walk  
**Output:** Lean Canvas 1-pager (PDF)  
**Sumber:** Ash Maurya

### Mg4 — Jenis MVP (TUGAS1 20%)
**Bahan:** Landing Page MVP, Concierge (manual behind-the-scene), Wizard of Oz (fake automation), Prototype (Figma click-through), mana untuk kapan  
**Metode:** Ceramah 100m (contoh: Dropbox video MVP, Zappos concierge) + Lab 170m (pilih jenis MVP untuk ide tim, buat MVP plan 1 hal: hypothesis, MVP type, metric, next step)  
**Asesmen:** **TUGAS1 (20%)** — Submit: (a) Lean Canvas final 1-pager, (b) Problem interview report 5-8 hal (15 responden: demografi, pain list, quotes, insight) + rekaman/transkrip evidence, (c) MVP plan. **Rubrik:** Canvas lengkap 30%, interview depth 40% (15 + quotes/insight), MVP plan rasional 20%, docs 10%. **Deadline:** Mg4 Jumat 23:59. Fabrication → 0 + etik.  
**Sumber:** MVP types

### Mg5 — Landing Page MVP (C3)
**Bahan:** Builder (Wix/Webflow/Carrd/Notion), copywriting (headline, sub, CTA), analytics (GA4 events: view/CTA click, Hotjar heatmap), domain edu  
**Metode:** Lab Hands-on 270m — build landing page live (headline+problem+solusi+CTA "Join Waitlist"), install GA, publish  
**Output:** Landing page URL + GA property  
**Sumber:** Landing Page guide

### Mg6 — Smoke Testing & Konversi (C4)
**Bahan:** Traffic acquisition (IG Ads dummy $5/day simulasi, campus poster QR, WA group), conversion rate (clicks/visits), A/B test headline, smoke test ethics  
**Metode:** Case 50m + Lab Analytics 170m (launch traffic 3 hari, collect 50+ visits, hitung conversion, iterasi headline) + Studio 50m retro  
**Output:** Conversion report (visits, clicks, rate, next insight)  
**Sumber:** Smoke Test

### Mg7 — Perancangan MVP Fungsional Sprint 0 (C4)
**Bahan:** Wireframe (Figma), arsitektur inti (FE: Next.js, BE: FastAPI/Mock, DB: SQLite), core feature 1 (must-have), backlog Sprint 1-2 (MoSCoW)  
**Metode:** PjBL Studio 270m — wireframe 5 screen + arch diagram + backlog Trello  
**Output:** Figma wireframe + arch PDF  
**Sumber:** Figma, SDLC

### Mg8 — UTS Pitching Validasi Pasar (25%)
**Format:** Per tim 15m — 8m presentasi (problem, interview insight (3 quotes), Lean Canvas, landing page hasil (visits, conversion, insight), traksi awal) + 7m Q&A panel dosen  
**Materi:** Mg1-7  
**Rubrik:** Interview depth 30%, Lean Canvas logis 20%, landing page traksi 30% (visits≥50, conversion terukur), presentasi & Q&A 20%. Minimal 50 untuk lulus UTS. Susulan H+7.  
**Sumber:** Bank UTS

### Mg9 — Pembangunan MVP Sprint 1 (C6)
**Bahan:** Core smart feature (mis. AI chatbot/ IoT dashboard/ platform marketplace), integration (API, DB), Scrum (daily standup 15m, review)  
**Metode:** PjBL Studio 270m — coding Sprint 1, demo mid-sprint  
**Output:** MVP v0.5 deploy (Vercel/Render) + changelog  
**Sumber:** Stack tim

### Mg10 — MVP Sprint 2 (C6)
**Bahan:** UI polish (design system), onboarding flow (tutorial 3 langkah), retention loop (notifikasi/push, gamifikasi), bug bash  
**Metode:** PjBL Studio 270m — polish + onboarding + UAT internal 5 users  
**Output:** MVP v1.0 + UAT feedback 5 users  
**Sumber:** Onboarding UX

### Mg11 — AARRR Pirate Metrics (C4)
**Bahan:** Acquisition (channel, CAC), Activation (onboarded), Retention (D7/D30), Referral (invite), Revenue (paying %) — dashboard Amplitude/Mixpanel simulasi, cohort analysis  
**Metode:** Problem-Solving 270m — buat dashboard AARRR dari data MVP (dummy jika belum ada traction)  
**Output:** AARRR dashboard (funnel)  
**Sumber:** AARRR, Amplitude

### Mg12 — Unit Economics (TUGAS2 25%)
**Bahan:** CAC (ads spend / paying users), LTV (ARPU×GPM×(1/churn)), churn rate, payback period, burn rate, runway (cash / monthly burn), break-even  
**Metode:** Problem-Solving 270m — hitung CAC/LTV dari data landing page + MVP, cohort burn  
**Asesmen:** **TUGAS2 (25%)** — Submit: (a) MVP fungsional v1.0 URL + repo + demo video 2m, (b) Dashboard AARRR + cohort, (c) Laporan Unit Economics 2-3 hal (CAC, LTV, churn, runway, insight). **Rubrik:** MVP fungsional 40%, AARRR dashboard 30%, Unit Economics benar 20%, docs 10%. **Deadline:** Mg12 Jumat 23:59.  
**Sumber:** Unit Economics

### Mg13 — Pendanaan Startup (C2)
**Bahan:** Angel (friends/family), Seed (YC, East Ventures), Series A/B, valuasi (pre/post-money, DCF dummy, comparables), cap table (founder 70%, ESOP 15%, investor 15% contoh), term sheet (liquidation preference, vesting)  
**Metode:** Ceramah 100m + Panel industri 170m (undang VC/angel Kampus) + Q&A  
**Output:** Simulasi cap table 1 hal  
**Sumber:** Venture Deals, YC

### Mg14 — Pitch Deck 10-Slide (C6)
**Bahan:** Silicon Valley standard: 1 Cover, 2 Problem, 3 Solution (demo GIF), 4 Market (TAM/SAM/SOM), 5 Product, 6 Traction (landing+ MVP metrics), 7 Business Model, 8 Go-to-Market, 9 Team, 10 Financials & Ask (funding need + use of funds) — storytelling (Hero's journey)  
**Metode:** Workshop 270m — draft deck 10 slides + peer feedback gallery  
**Output:** Draft deck PDF  
**Sumber:** Sequoia template, YC deck

### Mg15 — Pitching Rehearsal (C5)
**Bahan:** Delivery (voice, body, eye contact), timing 5m (PechaKucha), handling Q&A (jujur, data), dry run dengan mentor industri, feedback sheet  
**Metode:** Simulasi Pitching 270m — setiap tim dry run 5m + feedback mentor 10m + revisi  
**Output:** Feedback sheet + revisi deck  
**Sumber:** Pitch coaching

### Mg16 — UAS Demo Day (30%)
**Format:** Demo Day 170m (5-6 tim/hari) — 5m pitch (deck 10 slides), 5m live MVP demo (real click, bukan video), 5m Q&A panel investor/dosen (tanya market, CAC, defensibility)  
**Deliverables:** Deck final 10 slides + MVP URL + dashboard AARRR + laporan Unit Economics + video demo 3m  
**Rubrik:** Deck 30%, MVP fungsional 30%, AARRR/CAC/LTV 20%, delivery & Q&A 20% — minimal UAS 50, demo live wajib.  
**Sumber:** Rubrik UAS 088_5
