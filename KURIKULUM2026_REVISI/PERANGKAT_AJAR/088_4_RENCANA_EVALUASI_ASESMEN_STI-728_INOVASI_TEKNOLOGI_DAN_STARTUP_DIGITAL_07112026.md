## 3. Rincian Summative

### A. TUGAS1 — Lean Canvas + Problem Interview (20% — Mg4)

**Deliverables:** (a) Lean Canvas 1-pager (9 blok), (b) Problem Interview Report 5-8 hal (15 responden: demografi, pain list, 5 quotes verbatim, affinity map, insight 3), (c) MVP Plan 1 hal (hypothesis, MVP type, metric, next step) + Evidence (foto interview, rekaman/transkrip anonimized)  
**Rubrik (088_5 §A):** Canvas lengkap 30%, interview depth 40% (15 + quotes/insight, fab check), MVP plan rasional 20%, docs 10% — Minimal 55. Fabricated interview → 0 + sidang etik.  
**Deadline:** Mg4 Jumat 23:59 Classroom.

### B. UTS — Pitching Validasi Pasar (25% — Mg8)

**Format:** Per tim 15m — 8m presentasi (problem, 3 quotes insight, Lean Canvas, landing page hasil: visits ≥50, conversion rate, insight, next hypothesis) + 7m Q&A panel dosen  
**Materi:** Mg1-7  
**Rubrik:** Interview depth 30%, Canvas logis 20%, Landing traksi 30% (visits, conversion, A/B), presentasi & Q&A 20% — Minimal 50. Susulan H+7. Jika visits <30 tanpa justifikasi → maks C.  

### C. TUGAS2 — MVP Fungsional + AARRR/CAC/LTV (25% — Mg12)

**Deliverables:** (a) MVP v1.0 URL live (Vercel/Netlify) + repo + demo video 2m, (b) Dashboard AARRR (funnel: acquisition→revenue) + cohort (D7/D30) via sheet/Amplitude dummy, (c) Laporan Unit Economics 2-3 hal (CAC, LTV, churn, payback, burn, runway 12m, LTV/CAC >3)  
**Rubrik:** MVP fungsional 40% (live, E2E 1 core feature, no crash), AARRR dashboard 30% (funnel valid), Unit Economics benar 20% (formula & insight), docs 10% — Minimal 55.  
**Deadline:** Mg12 Jumat 23:59.

### D. UAS — Startup Demo Day (30% — Mg16)

**Format:** Demo Day 170m (5-6 tim/hari) — 5m pitch (deck 10 slides: problem→ask), 5m live MVP demo (klik real, bukan video, skenario 3 langkah), 5m Q&A panel investor/dosen (market size, CAC payback, moat, competitor, defensibility)  
**Deliverables:** Deck final 10 slides + MVP URL + dashboard AARRR + laporan Unit Economics + video demo 3m  
**Rubrik (088_5 §D):** Deck storytelling 30%, MVP fungsional 30%, AARRR/CAC/LTV 20%, delivery & Q&A 20% — Minimal UAS 50, demo live wajib (video saja → maksimal C), pitch overtime >7m → -10%.
